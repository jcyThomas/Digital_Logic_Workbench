Digital-Logic-Workbench-by-Thomas-Jin

Mode 1 — Basic Logic Gates Simulate AND, OR, NOT, XOR, NAND, NOR, and XNOR gates. Enter input bits and get the output, or generate a gate's truth table.

Mode 2 — Boolean Expression Simulator Enter expressions such as (A AND B) OR NOT C. The program identifies the variables, evaluates the expression for your chosen inputs, or generates the complete truth table.

Mode 3 — Half-Adder Enter two binary inputs and calculate both the sum and carry outputs to demonstrate a basic combinational circuit.
